# 论文整体架构与方法提纲（用于与导师讨论）


## 0. 一句话定位（研究对象 + 目标 + 手段）

- **研究对象**：塔吊吊装过程“吊钩端”近场高风险区域。
- **目标**：在复杂遮挡/光照/粉尘/振动条件下，实现可工程化落地的**动态避障与分级预警**。
- **手段**：双 LiDAR 提供三维几何测距与空间约束，工业相机提供语义识别与可解释性；以“标定与时空一致性”为前置，形成“感知—融合—定位建图—目标生成—雷视关联—风险评估—分级预警”的闭环。

## 1. 整体架构思路（闭环链路：输入→关键处理→输出）

### 1.1 总体管线（你和导师可用来对齐章节主线）

1) **系统构建与标定（第2章）**
   - 输入：双 LiDAR 点云、IMU、相机图像
   - 关键处理：相机内参、LiDAR–LiDAR 外参、LiDAR–相机外参；时间同步/延迟补偿；TF/坐标系规范
   - 输出：可复用的外参参数与统一时空语义接口（为后续融合、投影门控、距离计算打底）

2) **融合点云生成与定位建图（第3章前半）**
   - 输入：两路点云 + 外参 + 时间戳 + IMU
   - 关键处理：跨雷达时间对齐（最近邻+阈值门控）、坐标统一、融合发布；LIO-SAM（IMU 约束去畸变 + LiDAR 几何约束 + 因子图优化）
   - 输出：融合点云流、吊钩端连续位姿、静态地图（为跨帧对齐与“背景”建模提供空间基准）

3) **目标生成与短时跟踪（第3章后半）**
   - 输入：位姿约束下的近场 ROI 点云
   - 关键处理：ROI 裁剪/轻量预处理 → 局部滑窗背景 → 静动态分离（点到背景距离阈值+时序一致性） → 聚类 → 卡尔曼滤波短时跟踪
   - 输出：动态簇候选及其状态量（位置、速度、几何范围），静态障碍几何表征

4) **雷视融合与风险分级预警（第4章）**
   - 输入：点云侧 3D 动态轨迹 + 相机侧 2D 危险目标检测轨迹
   - 关键处理：YOLOv8 检测 + 时序稳定化；双向一致性关联（3D→2D 投影门控 + 反向验证）；轨迹级绑定；置信度融合；风险指标（距离/相对速度/TTC）；分级预警状态机
   - 输出：带语义的危险目标集合（车辆/unknown，可扩展到人员）、分级预警等级与触发目标 ID

5) **实验评估（第5章）**
   - 目标：从“模块有效”走向“系统闭环有效”（定位、关联一致性、预警提前量、实时性/稳定性）
   - 输出：面向论文结论的图表与指标闭环（每个结论对应证据）

### 1.2 两类风险目标的论文口径（需在讨论中统一）

- **人员（真实工地目标）**：论文摘要与研究背景主要面向“临近人员”等风险目标；这决定了语义类别、误报/漏报权衡、以及预警呈现方式。
- **车辆（缩尺/可控实验代表）**：在方法与实验章节中多处以“车辆”作为危险动态目标；其合理性在于“可复现、可控、可量化验证”的替代对象。

建议在论文与讨论中明确一句话：
- “本文方法面向施工人员等高风险目标；实验阶段以可控移动平台（车辆/小车）作为动态目标代表进行验证，方法可扩展到人员类别。”

### 第2章 吊钩端传感器系统构建与配准

#### 2.1 系统总体架构与硬件选型布置

**2.1.1 传感设备选型**
- 要解决的问题：近场全向几何感知 + 语义识别 + 强动态条件下的稳定运行。
- 方法：双 Livox Mid-360（主几何）+ 工业相机（语义）+ IMU（运动约束/去畸变）。
- 解决了什么：用传感器互补性覆盖 LiDAR 语义不足与视觉测距不稳。
- 输出：传感器规格与作用表。

**2.1.2 安装布局优化**
- 要解决的问题：吊钩结构遮挡、视场盲区、振动导致外参漂移。
- 方法：双雷达错位/对称布置 + 俯仰角设计；相机俯视；刚性基准 + 减振/限位。
- 输出：安装角度/布局原则（图示 + 工程解释）。
- 待补充：布局选择的“覆盖率证据”（例如可视化点云密度热力图或遮挡分析）。

**2.1.3 一体化盒体设计（SolidWorks）**
- 要解决的问题：防尘防水、线束疲劳、供电通信稳定、维护更换。
- 方法：上盖/下盖两体式；内部布局（重心、散热、应力释放）。
- 输出：结构外观、装配关系、内部布局与走线图。

#### 2.2 多传感器外参标定

**2.2.1 相机内参标定（张正友）**
- 要解决的问题：图像去畸变与点云投影需要可靠内参。
- 方法：棋盘格 + MATLAB 标定；以重投影 RMSE 评价。
- 输出：K、畸变参数、误差统计图。
- 待补充：最终 RMSE 数值与误差分布图（用于答辩时可信度）。

**2.2.2 双雷达外参自动标定与精配准**
- 要解决的问题：两路点云坐标统一，否则融合会“重影/错位”，影响定位与动态分离。
- 方法：先依据双雷达镜像安装关系、内旋顺序与主视轴夹角构造粗配准旋转初值，并将局部基线偏置统一到基准雷达参考系后写出初始变换矩阵；再采用“基准建图→目标逐帧 GICP→一致性筛选”的离线自动精配准流程。
- 输出：可直接写入运行时配置的静态外参矩阵 + 质量统计（fitness/收敛）+ 前后叠加对比图。
- 待补充：有效帧比例、收敛统计、重叠区最近邻距离判据等外参验证阈值。

**2.2.3 雷达—相机外参标定（3D–2D 重投影最小化）**
- 要解决的问题：雷视关联必须具备可解释的几何对应关系。
- 方法：标定板角点 3D–2D 对应，最小化重投影误差（LM/Ceres 思路）。
- 输出：T_l^c + 投影验证图（点云投影到图像）。
- 待补充：重投影误差统计与“可接受阈值”口径。

#### 2.3 通信链路与接口规范

**2.3.1 通信链路搭建**
- 要解决的问题：多源数据大吞吐下的丢包与延迟不可控会破坏融合。
- 方法：以太网 LiDAR + USB3 相机；小型交换机汇聚到工控机 eth0 单网口；小队列可丢帧策略。
- 输出：链路拓扑图 + 最小 ROS 话题接口表。
- 待补充：实际工程 topic 名、频率、队列长度配置（论文中建议写成“本文实现采用”）。

**2.3.2 时间同步与延迟补偿**
- 要解决的问题：跨传感器时间偏差导致投影错位、速度估计失真。
- 方法：PTP/GPS 同步讨论 + ROS 时间戳对齐 + 延迟估计补偿 + 时间窗门控。
- 输出：时序示意图 + 关键公式（delay/offset、时间窗 τ）。
- 待补充：系统实际延迟统计（均值/方差/95%分位），以及 τ 的最终取值依据。

**2.3.3 坐标系与 TF 接口规范**
- 要解决的问题：坐标系混用会导致距离/投影翻转或尺度错误。
- 方法：hook/base 参考系 + 静态外参 TF + 动态位姿 TF，强约束 frame_id 一致。
- 输出：TF 树结构图 + 命名规范。
- 待补充：最终 TF 命名（map/odom/hook_link/lidar1/lidar2/camera_link）。

### 第3章 基于融合点云的定位与空间危险区域检测方法

#### 3.1 双雷达点云实时融合方法

**3.1.1 双雷达原始数据接入与静态外参加载**
- 要解决的问题：在线融合必须先明确输入话题、消息类型和参考坐标系，否则离线标定结果无法无歧义地接入运行时系统。
- 方法：在 \texttt{livox\_merge} 中读取两路 LiDAR、两路 IMU 以及第2章输出的静态外参矩阵，统一写入 \texttt{body} 参考系。
- 输出：双雷达在线融合的输入接口和静态外参配置约定。
- 待补充：图示中给出实际 topic 名、配置项和 \texttt{body} 与基准雷达的关系。

**3.1.2 基于时间窗口的点云同步与坐标统一融合**
- 要解决的问题：双雷达异步输入若无稳定窗口机制，会导致重复发布、跨窗口错配和扫描结构混乱。
- 方法：逐点外参变换 + \texttt{ring offset} 重映射 + 缓冲队列时间窗口抽取 + \texttt{SyncLidar()} 20 Hz 主循环合并。
- 输出：统一到 \texttt{body} 的融合点云、保留时间字段的 Livox 融合消息以及高度切片结果。
- 待补充：窗口定义示意、缓冲参数、切片高度范围和等效 8 线解释。

**3.1.3 IMU 合并、时序发布与一次性自动调平**
- 要解决的问题：若 IMU 时间序列不单调或点云坐标仍随平台倾斜摆动，后续去畸变和 ROI 阈值都会失稳。
- 方法：先将多路 IMU 统一到 \texttt{body}，按时间窗口排序发布到 \texttt{/merged\_imu}；再以平均加速度估计重力方向，完成 \texttt{body -> body\_leveled} 的一次性调平。
- 输出：\texttt{/merged\_pointcloud\_leveled}、\texttt{/merged\_livox\_leveled}、\texttt{/merged\_imu\_leveled} 及其 TF 链。
- 待补充：调平持续时间、最小 IMU 样本数以及调平前后高度稳定性指标。

**3.1.4 融合结果发布与 LIO-SAM 接口适配**
- 要解决的问题：若输出话题、\texttt{frame\_id} 和扫描线参数与 LIO-SAM 假设不一致，融合点云将无法被正确使用。
- 方法：在系统启动中串联 \texttt{livox\_merge}、\texttt{leveler}、静态 TF 和 LIO-SAM，并将 \texttt{N\_SCAN} 从 4 调整为 8 以匹配融合后的 \texttt{ring} 范围。
- 输出：面向第3.2节定位模块的规范输入接口。
- 待补充：实际 launch 链路图和 \texttt{base\_link/body/body\_leveled} 的关系说明。

#### 3.2 基于融合点云的 SLAM 定位与静态地图构建（LIO-SAM）

**3.2.1 LIO-SAM 输入适配与系统接口**
- 要解决的问题：双雷达融合结果若不能以当前代码要求的消息类型、frame 和扫描结构输入，定位链路无法直接复用。
- 方法：以 \texttt{/merged\_livox\_leveled} 和 \texttt{/merged\_imu\_leveled} 作为输入，保留 Livox 点时间偏移字段，并将 \texttt{N\_SCAN} 从 4 调整为 8。
- 输出：面向 \texttt{imuPreintegration/imageProjection/featureExtraction/mapOptmization} 的规范输入接口。
- 待补充：图示中标出 topic、frame、\texttt{CustomMsg} 与 \texttt{cloud\_info} 的关系。

**3.2.2 点级去畸变与 range image 组织**
- 要解决的问题：若不按点时间对扫描做去畸变，摆动工况下单帧刚体假设失效，后续特征提取会系统偏移。
- 方法：\texttt{imageProjection} 使用 IMU 与增量里程计恢复点到扫描起始时刻的相对位姿，并按 \texttt{ring} 与列索引构造 \texttt{rangeMat}。
- 输出：去畸变点云、\texttt{startRingIndex/endRingIndex/pointRange} 等前端共享数据。
- 待补充：IMU 查询时间窗、\texttt{Horizon\_SCAN} 设置和等效 8 线的组织示意。

**3.2.3 特征提取与 scan-to-map 前端配准**
- 要解决的问题：已去畸变点云仍需进一步筛出稳定几何约束，才能在有限算力下实现可靠的 scan-to-map 优化。
- 方法：\texttt{featureExtraction} 进行曲率计算、遮挡点剔除和角点/面点提取；\texttt{mapOptmization} 构建局部地图并执行前端残差优化。
- 输出：当前帧配准结果、关键帧更新以及 \texttt{cloud\_registered}。
- 待补充：角点/面点阈值、局部地图构建范围和关键帧选取条件。

**3.2.4 IMU 预积分、因子图优化与位姿地图输出**
- 要解决的问题：仅靠前端配准无法保证连续高频位姿和长时间稳定性，需要惯性约束与后端平滑共同修正。
- 方法：\texttt{imuPreintegration} 在因子图中联合优化位姿、速度和 IMU 偏置；\texttt{TransformFusion} 融合高频惯性里程计与低频建图结果。
- 输出：\texttt{lio\_sam/mapping/odometry}、\texttt{odometry/imu}、静态地图和路径结果。
- 待补充：图优化重置策略、回环开关在系统中的功能位置，以及输出话题对第3.3节的接口关系。

#### 3.3 基于 M-detector 的动态点检测与候选目标状态生成

**3.3.1 动态检测输入组织与短时历史深度图构建**
- 要解决的问题：动态检测不能直接在原始雷达流上做逐帧差分，需要在统一世界系下维护短时历史观测以稳定描述遮挡关系。
- 方法：以 \texttt{/lio\_sam/mapping/cloud\_registered} 和 \texttt{/lio\_sam/mapping/odometry} 为输入，构建 \texttt{depth\_map\_list}，并结合 \texttt{buffer\_delay}、\texttt{depth\_map\_dur} 和自体/盲区过滤组织历史深度图。
- 输出：面向 Case1/2/3 判别的短时历史深度图序列。
- 待补充：深度图时间窗、最大缓存数量、\texttt{blind\_dis} 和自体掩膜配置的最终取值。

**3.3.2 基于遮挡关系的三类动态点判别**
- 要解决的问题：需要把“深度不一致”进一步分解为边界变化、遮挡体运动和被遮挡体显露三类不同动态来源。
- 方法：按 \texttt{Case1}、\texttt{Case2}、\texttt{Case3} 顺序执行进入判据、地图一致性检查、深度一致性检查和连续次数验证。
- 输出：逐点动态标签 \{STATIC, CASE1, CASE2, CASE3, INVALID\}。
- 待补充：\texttt{occluded\_map\_thr1}、\texttt{occluded\_times\_thr2}、\texttt{occluding\_times\_thr3} 及各类深度阈值的说明。

**3.3.3 欧式聚类候选生成与短时目标跟踪**
- 要解决的问题：逐点动态标签无法直接用于目标级分析，需提升为候选目标表示并跨帧关联形成连续状态量。
- 方法：M-detector 已输出 \texttt{odom} 系动态点云，\texttt{pointcloud\_tf\_bridge} 将其对齐至 \texttt{map} 系后，由 \texttt{dyn\_cluster\_node} 执行欧式聚类并输出包围盒中心；随后 \texttt{dynamicTracker} 采用二维常速度模型、时间扩张门控和确认/删除规则进行短时跟踪，并对 z 方向做低通平滑。
- 输出：候选中心序列（\texttt{PoseArray}）、聚类标记、聚类点云，以及连续 ID、平面速度、\texttt{tracked\_centers} 和短时预测轨迹。
- 待补充：聚类半径与规模阈值、桥接的 TF 回退机制、门控参数、确认/删除阈值以及预测时域对后续预警模块的接口说明。

### 第4章 基于雷视融合的避障预警策略

#### 4.1 视觉侧高风险目标识别

**4.1.1 危险目标（车辆）检测模型与部署**
- 要解决的问题：点云动态簇缺少语义，难区分“危险目标”和“非危险动态干扰”。
- 方法：YOLOv8 输出 bbox + 置信度 + 类别（实验为 vehicle）。
- 输出：2D 候选集合 D(t)。
- 待补充：推理端到端延迟统计（决定时间窗 τ 的合理范围）。

**4.1.2 检测结果时序稳定化处理**
- 要解决的问题：漏检/抖动会引发关联与预警跳变。
- 方法：帧间匹配（IoU+距离/匈牙利或贪心）→ 丢检容错 M → 置信度平滑 + 滞回（T_on/T_off）。
- 输出：稳定的 2D 轨迹（track_id + 平滑置信度）。
- 待补充：匹配策略选择与阈值；M、T_on/T_off 的取值依据。

**4.1.3 点云动态目标融合接口与数据结构定义**
- 要解决的问题：异步链路下的时间语义与坐标语义不一致会导致错配。
- 方法：缓存队列 + 延迟补偿 \hat{Δ} + 时间窗门控 τ；明确 frame_id/内参版本。
- 输出：可关联的“2D 轨迹 + 时间语义”。
- 待补充：\hat{Δ} 的估计方法与 τ 的最终取值。

#### 4.2 雷视融合策略

**4.2.1 融合总体流程与设计原则**
- 核心思想：LiDAR 主几何（距离/速度/TTC），视觉供语义与验证（减少误报）。
- 输出：语义增强的 3D 目标集合。
- 待补充：降级策略（视觉失效/点云失效时输出规则）。

**4.2.2 双相一致性关联策略（双向验证）**
- 要解决的问题：单向投影重叠容易因偶然重叠/遮挡导致错绑。
- 方法：2D→3D 门控（投影落入 bbox/覆盖率/投影 IoU）+ 3D→2D 反向一致性（跨帧趋势/尺度合理性）+ 一对一分配。
- 输出：候选关联对 + 最终绑定结果。
- 待补充：覆盖率/IoU/最小投影点数阈值；关联得分函数；分配算法选择。

**4.2.3 轨迹级绑定与遮挡鲁棒融合**
- 要解决的问题：短时遮挡导致频繁切换，污染速度/TTC。
- 方法：绑定状态机（Unbound/Tentative/Bound/Hold），进入/退出阈值 K/L。
- 输出：短时遮挡下仍连续的语义绑定。
- 待补充：K/L 取值与依据；何时降级为 unknown。

**4.2.4 置信度融合与语义标签输出**
- 要解决的问题：避免“语义不可信但强行输出危险目标”。
- 方法：融合置信度 s_fuse = w_v * s_det + w_l * s_lidar + 滞回阈值；输出 vehicle/unknown。
- 输出：语义标签 + 融合置信度。
- 待补充：s_lidar 的构造与归一化；权重与阈值的标定方式。

#### 4.3 风险判定与分级预警策略

**4.3.1 静态障碍：距离/侵入阈值预警**
- 要解决的问题：静态结构侵入近场安全区需稳定触发且误报可控。
- 方法：最小距离（可做分位数鲁棒化）+ 危险源等效半径 + 滞回 + 最小持续时间。
- 输出：静态风险触发与预警等级输入。
- 待补充：r_h、D_on/D_off、分位数 q 或点数支持 n_min 的最终设置。

**4.3.2 动态目标：相对速度/TTC 风险**
- 要解决的问题：仅距离阈值预警提前量不足。
- 方法：接近速度 v_rel 与 TTC；可用等效半径修正有效距离；对速度抖动做门控/平滑。
- 输出：动态风险量（d、v_rel、TTC）。
- 待补充：T_warn/T_danger、r_o 的口径与数值。

**4.3.3 分级预警状态机**
- 要解决的问题：输出稳定且可解释（避免“报警疲劳”）。
- 方法：Normal/Warning/Danger；距离与 TTC 双门控；滞回 + 最小持续时间；多目标取最大风险。
- 输出：系统预警等级 + 触发目标 ID + 可解释原因（距离/TT C）。
- 待补充：状态机转移表（完整阈值、持续时间、unknown 策略）。
